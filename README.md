# Galton Board - A Monte Carlo Simulation with AWS Lambda
This project simulates a Galton board using a Monte Carlo Simulation. A Galton board can be thought of a box with a series of pegs aligned in such a way that when a ball is dropped into the Galton board it has a chance to bounce left or right before moving on to the next layer. It keeps going until it reaches the bottom where it is collected into a bin. By comparing the relative number of balls in the bin you may observe the probabilities that a ball will fall into the bin. By taking all of those probabilities together, you can observe a normal bell curve (assuming the probability of bouncing left or right is 50/50.
That said, this Galton board has a twist: when a ball changes its direction, the odds that it keeps going in that direction get set to above 50% (Normal odds + biasJump). However, for every layer the ball clears without changing directions, the ball becomes less likely to keep going in that same direction (current odds - adj). A ball also has a chance of simply being more likely to go in a certain direction by default (odds + drift). This effects whether or not the graph is left leaning or right leaning. The use of a clamp in this project simply locks the current bias in any given direction to Normal +- 0.5.
